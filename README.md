# SQL Filtering Practice – Task 22

## 📌 Project Overview
This project focuses on practising SQL filtering techniques using the `WHERE`, `IN`, `BETWEEN`, and `LIKE` operators. It is part of my Data Analytics Internship at Veda Technology.

## 🎯 Objective
To understand and apply common SQL filtering conditions to retrieve specific records from relational databases.

## 🛠️ Tools & Technologies
- MySQL
- PostgreSQL
- SQL
- Northwind-inspired Sample Dataset

## 📂 Project Deliverables
1. 12 SQL queries demonstrating different filtering techniques.
2. Query execution results in CSV format.
3. Sample database schema and data.
4. Project documentation and report in PDF format.

## 📚 SQL Concepts Covered
- WHERE clause
- IN operator
- BETWEEN operator
- LIKE operator
- AND conditions
- Comparison operators
- ORDER BY
- JOIN
- GROUP BY
- HAVING

## 📊 Dataset
A compact Northwind-inspired sample dataset containing:
- Customers
- Products
- Employees
- Orders
- Order Details

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open MySQL Workbench or PostgreSQL.
3. Execute `sample_northwind_schema_and_data.sql`.
4. Execute `task22_sql_filtering_queries.sql`.
5. Review the query outputs and compare them with the CSV result files.
